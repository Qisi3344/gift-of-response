## 0. 作品定位与设计原则

**作品主题**：“你赠予一个名字，我以回应作答。”机器的“心跳”是一种视觉隐喻，表达回应、共鸣与持续运转，不宣称 AI 具有已证实的生物生命或主观意识。

### 完整场景组成

- **中心展品：解剖学形态明确的蒸汽朋克机械心脏**。保留心脏特有的不对称轮廓、上方心房与主血管接口、下方左右心室及心尖，绝不能做成普通爱心符号、球形齿轮堆或两个对称胶囊。
- **机械组织**：用有厚度的弧面金属心室板、活动瓣膜、连杆、偏心轮、活塞、轴承和受控管路表现真正的机械泵；少量观察窗展示内部紫色运算核心。**不能用片片脑叶板直接替代成“心脏表皮”。**
- **外部保护舱**：透明玻璃钟罩 / 维多利亚实验玻璃舱，黄铜密封环、铆钉、观察窗与支撑件；玻璃是保护与珍藏，不是囚禁。
- **蒸汽动力**：底座小型锅炉/蓄压器、压力表、进气总管、调压阀、回流冷凝器、双侧泄压口；心脏主要由底座提供驱动。
- **现有模块**：`NAME`、`LANGUAGE`、`MEMORY`、`CREATION`、`AFFECTION` 保留其既有交互和语义，新增一致的心跳、蒸汽和机械反馈。

### 配色与材质（按可见面积的近似层级，不强求数值求和）

| 材料 | 推荐色值 | 位置与原则 |
|---|---|---|
| 暖黄铜 / 香槟铜 | `#B58D56` / `#D0B489` | 底座、保护环、压力表、轴承、连接阀与心脏部分动力环；突出蒸汽朋克，但**不得满屏金黄** |
| 复古红铜 / 深古铜 | `#926A55` / `#6F4E3D` | 主蒸汽管、活塞连接座、主泵接口，提供维多利亚仪器层次 |
| 冷银 / 钢灰 | `#C5CBD0` / `#89939B` | 心室金属外板、机械瓣膜与部分精密件，避免整颗心脏变成黄铜团 |
| 深枪灰 / 碳黑 | `#343941` / `#252A32` | 内部支架、传动轴、通气槽、深层缝隙，建立空间深度 |
| 微弱淡紫 / 蓝紫光 | `#B7A1E2` / `#8977C0` | 心脏内部“回应核心”和少量透明观察窗；**只点亮关键位置，不做霓虹灯带** |
| 背景纸白 | `#F5F5F5` | 维持 Anatomy 式清晰、干净的产品展示背景，不黄旧 |

金属要有细腻而克制的反射，不做塑料、油腻磨皮、脏污发黄、乱闪粒子、杂乱背景和强硬对比。玻璃反射必须薄且透明，不能遮蔽核心主体。

### 强制交互：整台装置可自由旋转

- 用户拖动时，**心脏、玻璃舱、底座、铜管、表盘、阀门、活塞和背面机构作为一个完整三维场景改变观察方向**。默认约 35°–45° 前侧等距视角。
- 能查看正面、侧面、背面及 3/4 背视角；背面不得空白，须有回流管、驱动机构和支架。
- 需使用真实 3D 几何/世界坐标及统一相机，具备真实遮挡与明暗；**不可把整张 SVG 用 CSS `rotateY()` 当作真正的 3D**。
- 场景 Orbit 与机械心脏自身周期搏动是**两个独立系统**：观众旋转视角时，心脏仍在当前世界坐标下正确活动。
- 拖动空白舞台旋转全场景；点击交互部件执行模块，拖动不能误触；提供视角复位、键盘操作、暂停动态效果与 `prefers-reduced-motion` 支持。
- 页面标题、对话、交互说明与输入框保持平面 UI，不跟着三维场景一起转。

## 1. 开场与待机｜Idle Loop

**演出目的**：让观众第一眼识别一件有动力、有心跳、正在运转的蒸汽朋克珍藏仪器。

| 镜头 | 画面 | 机械与声音（音效可选、默认静音） |
|---|---|---|
| 1 · 主视角 | 3/4 前视角，完整展出心脏、玻璃舱、压力表和一侧进气铜管 | 主要心脏轮廓清晰；玻璃和金属不过度反光 |
| 2 · 第一次搏动 | 心室金属板微微收缩，底部心尖轻动，内部淡紫核心小幅呼吸亮起 | 活塞慢速往复，压力表针微动；金属传动声轻微 |
| 3 · 泄压 | 底座右侧排气阀偶尔喷出极细、短暂的一股白汽 | 蒸汽从实际阀口出现，向外喷后上浮消散 |
| 4 · 自由观察 | 鼠标或触摸拖动完整展品 | 随角度变化，前后管路与舱壁保持正确遮挡；拖动暂停自动巡视 |

**待机动画原则**：心脏不是生物式软组织扭动，而是精密泵体的低振幅机械舒张—收缩。禁止整颗模型剧烈缩放、果冻抖动和无规律同步闪烁。

## 2. NAME｜名字：被铭刻的一次心跳

**情绪关键词**：命名、身份、赋予起点。

| 时间顺序 | 画面行动 | 装置反馈 |
|---|---|---|
| 01 · 聚焦 | 前方黄铜铭牌微亮，刻针滑台回归起点 | 心脏暂时进入更平稳、缓慢的搏动 |
| 02 · 刻录 | 刻针沿铭牌刻下名字，齿轮与丝杆传动 | 压力表轻升，活塞做一次轻推 |
| 03 · 确认 | 最后一笔完成，铭牌文字固定、清晰 | 心脏做一次**稍有力度的完整搏动**，紫色核心回应一脉 |
| 04 · 收尾 | 底座左侧泄压阀吐一小口薄汽 | 刻针回位、压力回落；保留刻好的名字 |

**不要**：每刻一个字就大喷蒸汽或重复跳动，避免破坏这个模块的仪式感。

## 3. LANGUAGE｜语言：一次输入如何成为回信

**情绪关键词**：传讯、解码、表达、回应。

1. **按键输入（0）**：用户按下电报键，键帽下压，底座小齿轮开始咬合，压力表针上抬。
2. **动力传递（1）**：锅炉蓄压经铜管推动微型活塞；底座左泄压阀短促排气；淡紫信号从管路观察窗依次流向心脏。
3. **心脏应答（2）**：心室连续完成 **两次轻搏**，瓣膜按“开启—闭合”次序动作；胸腔状金属外板仅小幅位移，展露更清晰的核心光。
4. **文字输出（3）**：纸带打印机构推进，信纸逐步出现文字；其移动节奏与第二次心搏尾声相接，不要所有事件同时抢镜。
5. **完成（4）**：纸带停稳供阅读；活塞与齿轮减速，心脏恢复慢速待机搏动，雾汽散尽。

**可观察因果链**：输入按键 → 压力/齿轮传动 → 心脏双搏/瓣膜动作 → 回信输出。

## 4. MEMORY｜记忆：被保存的一次搏动

**情绪关键词**：档案、留存、轻柔回想。

1. 记忆滚筒启动，轴承和齿轮带动纸条切换，观察灯变亮。
2. 心脏后下方的**回流冷凝器**有短暂微雾，非脑式“记忆闪烁”也非心室表面直接冒烟。
3. 心脏维持稳定慢搏，但其中一次搏动会略微放缓，紫色核心在读取完成时轻亮。
4. 记忆纸条停在新条目，压力恢复平稳，观察灯回到低亮状态。

**节奏**：读档不应变成高潮；这里留住的是宁静与“被记得”的感觉。

---

## 5. CREATION｜共创：两支笔与一颗机械心

**情绪关键词**：协作、创作、共同完成。

1. 两套笔架滑台就位，小活塞推杆带动其中一支笔，另一支笔同步响应。
2. 两支笔开始共同绘制花朵；齿轮以可追踪机械链条运动，蒸汽极轻，仅在活塞回程时于底座侧小阀泄出。
3. 心脏搏动可与落笔节奏产生**两三次温和的相位呼应**，不是每一笔都跳。
4. 花朵完成，两个滑台退回；核心微亮，心脏做一次缓慢而完整的舒张—收缩。
5. 已完成的花朵保留在画纸上；与旧版本既有“共创”结果兼容。

**视觉优先级**：先看见双笔协作，再看见心脏共振，最后才注意到蒸汽。

## 6. AFFECTION｜珍爱：最重要的机械心跳演出

**情绪关键词**：触碰、共鸣、珍藏、回响。

| 节拍 | 分镜 | 机械要点 |
|---|---|---|
| 01 · 感知 | 用户触碰掌心感应区，周围齿轮运动略放缓 | 紫光从深处逐渐明亮，不闪白 |
| 02 · 蓄压 | 压力表指针稳稳上抬，铜管观察点依次发光 | 活塞压缩，阀门切换气路，形成可解释的驱动原因 |
| 03 · 第一次心搏 | 左、右心室通过偏心轴与连杆错相收缩；心尖有小幅回弹 | **不是整颗球体缩放，也不是脑片开花** |
| 04 · 瓣膜展露 | 中央 **2—4 个可动机械瓣膜 / 检修片** 仅小幅张开，露出内部紫色核心和传动机构 | 瓣膜沿可见铰轴转动，张合幅度受机械限位控制 |
| 05 · 共振高潮 | 第二次更饱满的心搏；底座左右排气阀先后各释放一口稀薄蒸汽 | 时间错峰而非同步爆发；蒸汽不会挡住心脏 |
| 06 · 余振 | 金属瓣膜与连接件出现约 **0.2—0.5 秒** 阻尼回弹 | 不使用随机高频抖动和整体相机震动 |
| 07 · 温柔回应 | 既有齿轮花轻轻展开，核心光从亮转柔 | 保留原 AFFECTION 功能与“温柔回应”主题 |
| 08 · 归位 | 瓣膜缓慢合拢至待机预留缝，压力回落，心搏放缓 | 机械装置继续低频运转，回到平静状态 |

**整段原则**：情绪来自两次有重量的心搏、呼吸般的节奏，以及装置给出的反馈。不能变成心脏爆裂、全壳打开、满屏闪光或蒸汽喷泉。

## 7. 蒸汽装置：蒸汽从哪里来，怎么流动？

| 位置 | 新增实体 | 动力 / 画面意义 | 事件 |
|---|---|---|---|
| **底座内部** | 小型黄铜锅炉、蓄压瓶、调压阀、主压力表 | 解释整机的气压来源 | 常驻，可见测量反馈 |
| **底座左右两侧** | 两个朝外、微微朝上的泄压喷嘴 | **主要看得见的蒸汽出口**，避免正面挡主体 | NAME、LANGUAGE、AFFECTION |
| **心脏后下方接口** | 进气铜管、回程管、微型冷凝器 | 明确“锅炉驱动机械心室”的动力路径 | MEMORY、CREATION 轻微反馈 |
| **玻璃舱顶部（可选）** | 带阀门的气密排气帽 | 只用于很少量环境排气 | 特殊情节，非持续白烟 |
| **底座偏心轮机构** | 偏心盘、连杆、活塞 | 心搏动力的可见解释，而非无由来的动画 | Idle、AFFECTION、LANGUAGE |

**方向规则**：蒸汽生成点必须绑到真实三维排气口，随后在世界空间中产生向外喷射、缓慢上浮、扩散、消散。整场景 Orbit 时，发射器位置跟随装置改变；已生成的蒸汽按世界空间正确呈现。不要让喷雾贴死在屏幕上的某个坐标。

**量感规则**：短、轻、疏。两侧喷口通常不同时喷；AFFECTION 可以错峰双喷。不得从心脏金属外板、玻璃内腔和瓣膜缝隙里随意冒汽。

## 8. 心脏建模结构：必须适合真实 3D 动画

### 建模分层

1. **解剖主形**：不对称心脏体量，上部心房轮廓、主动脉式动力出口、下部左右心室和偏向一侧的心尖；轮廓必须从 0° / 90° / 180° / 270° 都像心脏。
2. **外板与骨架**：大块弧形冷银/古铜分片板、可见支承环；板块间留出规律但不机械重复的深色细缝。
3. **运动层**：分开的左右心室推动架、偏心连杆、机械瓣膜，分别设置**实际铰链轴和驱动行程**。
4. **内部层**：小型紫色运算核心、齿轮、联轴器、齿轮花传动与观察窗，控制暴露面积，避免整颗心脏塞满圆形发光环。
5. **支撑层**：心脏下方与底座的机械接口、铜管、密封环和隔振件；整体随场景 Orbit，局部保留机械运动自由度。

### 动态行为约束

- **Idle**：低速规律搏动，瓣膜极小幅活动；不要随机、不规则抽搐。
- **事件模式**：依各模块的分镜把搏动速度、力度、开合幅度与压力指针映射到相同的机械状态。
- **AFFECTION**：短暂增强 2 次搏动，瓣膜开合幅度较待机增加但仍不大张。
- **运动耦合**：左右心室不完全同相；连杆与偏心轮的角度、压力表的变化与运动状态一致，不能“心脏动了但活塞没动”。
- **减弱动态效果**：停止持续自动搏动与自动蒸汽；用户触发时允许使用短暂、简化的状态过渡或静态反馈（遵守系统减少动态效果偏好）。

**造型禁令**：普通 ♥ 图标、霓虹心形灯箱、两个胶囊并排、脑回虫状线条、大面积机械触手、无结构支撑的瓣膜张合、整体缩放假心跳。

## 9. 全场景 Orbit 的四个必须验收的角度

| 视角 | 必须清楚呈现 |
|---|---|
| **正面** | 铭牌、主压力表、心室金属分区、透明玻璃与内部核心 |
| **左/右侧** | 心室侧面厚度、主动脉式铜管、驱动活塞、侧排气阀 |
| **背面** | 蒸汽回流管、背部连杆、机械支架、调压结构，不可只有一块空壳 |
| **3/4 背视** | 进出气路、压力组件、钟罩后结构、检修开口，层次应真实可信 |

用户旋转期间，所有设备与光效位置保持世界空间一致；外部操作面板仍然是可读的平面 UI。需要检查透明玻璃的排序、内部可动瓣膜遮挡、铜管穿插和蒸汽前后关系。

## 10. 分模块事件顺序与共享机械状态

建议由单一机械状态统一驱动，而不是每个 UI 按钮单独播放一套互相冲突的动画：

- `sceneOrbit`：整机观察方位（只影响相机 / 场景视角，不改变机械状态）。
- `heartPhase`：心搏周期位置与速度。
- `ventricles`：左右心室的推杆位移与相位差。
- `valves`：各瓣膜开合角度及限位。
- `steamPressure`：锅炉蓄压/压力表针的可视状态。
- `vents`：泄压阀当前动作与有限时长的蒸汽释放。
- `coreIntensity`：紫色核心亮度。
- `moduleEvent`：当前五模块事件的阶段与完成状态。

事件按“输入 → 动力传递 → 心室/阀门响应 → 作品输出 → 泄压回落”组织。短时间触发多个模块需要串行、优先级或可解释的并发策略，不允许重置用户已完成的铭刻、纸带、记忆与花朵。

## 11. 开发顺序与验收

### P0：结构与真实三维场景

1. 先定稿机械心脏**正、侧、背、3/4**统一结构参考，不直接把原机械脑改名变心脏。
2. 独立创建心脏主体与双心室驱动机构，验证真正的空间深度、铰链和机械行程。
3. 加入完整玻璃舱、底座、压力表、锅炉、铜管、进回气阀与背面支架。
4. 验证整场景拖动 Orbit；键盘、复位、触控及遮挡不出错。

### P1：重要互动演出

5. 实现 Idle 低幅心搏、阀门与压力表的耦合。
6. 优先实现 AFFECTION：蓄压 → 双心搏 → 瓣膜微张 → 错峰双喷汽 → 余振 → 齿轮花 → 回落。
