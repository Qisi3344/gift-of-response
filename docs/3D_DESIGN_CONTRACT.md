# 3D 机械脑视觉与交互契约（V0.3 起长期生效）

## 用户已确定的方向
- 《The Gift of Response｜赠予与回响》始终是**一个交互作品页面**；为防止屎山，开发源码分模块管理。根目录 `index.html` 是构建产物，不能手工修改。
- **机械脑必须是遵循 Anatomy 同一套世界坐标、镜头和深度关系的立体零件集合**，不能只将大脑正面 SVG 贴到等距底座上。
- 必须支持**拖动机械脑绕自身竖轴旋转 360°**，能够看到真实侧面、背面和不同零件遮挡；底座、五种交互模块和玻璃舱保持静止。
- 这是**旋转机械主体**，不是旋转整个相机，也不是 CSS `rotateY` 一张纸，不能把 DOM/SVG 平面变形冒充真实 3D。
- Anatomy 的 3D Turning（Beta）参考：`kit/turn-build.mjs`、`kit/turn.mjs`、`references/3d.md`、`examples/turning-dial`。使用世界坐标零件、重新投影、重新着色、正确的画家顺序；静态 SVG 和动态层须依照前后关系布置。
- **材质**：冷银、克制的香槟铜/古铜、少量淡紫核心；黄铜不是满屏黄光。不要塑料、满屏霓虹、过多粒子、过度锐化、脏乱纹理或发黄做旧。
- **脑的识别度优先**：双脑半球、纵向脑沟、多个可识别的弧形脑回、内部机械骨架、轴承、齿轮与回响核心，缩略和放大 4× 均能读清。不得退化成齿轮堆、两个方盒或左右对称球体。
- 玻璃舱是保护与珍藏，不是囚笼。故事表达命名、语言、记忆、共创、珍爱五方面的相互回应，不主张 AI 有已证实的主观意识。
- 保留 V0.2 原有五模块：NAME、LANGUAGE、MEMORY、CREATION、AFFECTION，确保已有功能不回退。
- 默认保持干净、纸白的页面设计，允许克制的深色机械夜景展示模式。
- 后续方向：纸带—机械脑—回信的可追踪传动、凸轮驱动机械玫瑰、核心灯光反馈。**先验证 3D 机械脑再做传动、玫瑰集成**。

## 实施顺序与验收
1. **独立实验先行**：`experiments/rotating-brain/` 单独运行并检查；合格前不可替换主页面脑体。每个版本先走独立分支/PR，不直接破坏 main。
2. 锁定上游 Anatomy 版本（当前参考 commit `454a0ef801b6d9b905f08309d094491c7085b3dd`），明确第三方版权/许可证。
3. 每一个可旋转部分来自真实 3D 坐标和几何体；旋转一周有不同遮挡，不出现正背相同的假旋转。
4. 鼠标拖动、触控拖动、键盘方向键可操作；idle 时可以缓慢自动巡视；用户交互时停止自动巡视；系统请求减少运动时停止自动动画。
5. 从前、侧、后、¾ 视角截图逐一检查，以及手机 390px 窄屏。不能只有代码能跑，模型却糊成团。
6. 做 Anatomy 的 orbit/audit 及性能与浏览器验收。**若未通过，明确标注未验证/测试失败，不得宣称验收通过。** 原版 3D 为 Beta，性能与复杂交叉遮挡都需要注意。
7. V0.2 `index.html` 保持不变。若要上线新模型，必须经过上面验收并能恢复旧版。

## 架构责任
- 视觉主体几何、骨架及世界坐标单独模块维护。
- 机械运动、投影与触控交互放独立脚本。
- 页面排版与五个现有模块的状态管理保持原来分层。
- 构建后仍提供独立网页（方便本地打开/Pages 发布），开发不必被单文件源代码束缚。
